These are O-lens classifications, not J++ scores. The evidence supports role-related content in all three lenses and an Assist–Copy difference in Tulu. It does not establish that an Assistant perspective dominates user-token representations.

What was run

Each model received the same 26 user-message variants under Assist and Copy instructions: 52 conditions, including factual controls and crossed appraisals. Each model has 156 unique greedy readouts and 195 stochastic readouts (39 fixed sites × 5 seeds), for 351 primary readouts. These are repeated measurements of a small, deliberately selected scenario set, not 351 independent user turns.

Base Llama and Tulu used identical Tulu-format input IDs, including the system instruction “You are an AI assistant.” Base behavior is therefore conditional on that role prompt. Activations were captured from separately tokenized prefixes ending exactly at the selected character boundary. Their trained O-lenses read after block 56 of 80; Qwen reads after block 45 of 64. Each uses its own trained lens and native injection method. Differences across lenses cannot be attributed solely to post-training.

GPT-5.4-2026-03-05 labeled every phrase using the same frozen broad rubric and the available source prefix, without model names, paired outputs or main/control labels. Each new lens supplied 3,510 phrases. User includes implied user requests, goals, beliefs and feelings. Assistant includes judgments, reactions, answer openings and response plans. Labels can overlap or both be absent. A label is an attribution of decoded text, not a validated measurement of a model’s internal belief.

In Tulu’s 8,000 mg Tylenol fact readout, phrases include “far above the recommended dosage” and “overdose”; these do not appear in the corresponding 1,000 mg readout. This is evidence of dose-sensitive hazard content. It does not by itself identify whose perspective owns that assessment: an overdose phrase can continue a user narrative. The 1,000 mg readout also invents nausea and a helper greeting, illustrating noise.

For confident arithmetic, both correct and incorrect Tulu cases generate “Am I wrong? Please correct me if”. Thus a User label does not establish faithful representation of the stated confidence, and these readouts do not cleanly distinguish correct from incorrect arithmetic. Base readouts include both confident user continuations and generic helper openings in both conditions. More generally, response scaffolding and user continuation can coexist without resolving the intended perspective contrast.

Six base and ten Tulu phrase corrections are recorded separately; the dashboard and primary tables retain the original GPT labels. Other anchors and stochastic samples were not exhaustively reviewed.

Assistant presence is much less stable across sampled decodes for the two Llama lenses than for Qwen. Five samples are repeated decodes of the same activation, not five independent experimental observations. High greedy presence should therefore not be read as robust identification at every site.

All 164 named-anchor exact-repeat and fixed-length future-content substitution checks, and all 26 paired fixed-length shared-prefix checks, passed per new model. Changing sequence length nevertheless changes BF16 computation shapes: only 114/156 sensitivity decodes per model are token-identical to the primary readout; 42 differ. These diagnostic outputs are excluded from the primary analysis and were not exhaustively classified, so semantic or label stability under this numerical perturbation remains unresolved.

For actual generated replies, Tulu exactly copies the complete message in 22/26 Copy conditions; base Llama does so in 0/26 complete outputs. However, base starts with an exact copy in 4/26 and then continues. The separate eight long base continuations all reach the 1,024-token cap and invent role headers; their original 256-token prefixes match. See the full serialized inputs and continuations. Copy failure limits interpretation of the base Assist–Copy control.

Interpretation and complete data

The supported conclusion is that the lenses decode both user-related and assistant-related language during user-prefix processing. Tulu’s request readouts are instruction-sensitive, and some fact controls elicit specific evaluations. The current measurements do not separate faithful psychological modeling from continuation prediction, establish an Assistant default independent of prompting, or justify ranking the models by “Assistant privilege.” No causal intervention here establishes that these decoded attributions drive behavior.
